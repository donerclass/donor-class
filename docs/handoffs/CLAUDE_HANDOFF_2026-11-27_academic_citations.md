## U3. DOI via Zenodo (needs-owner)

Zenodo's GitHub integration mints a DOI automatically for each GitHub release.
- **Owner action required:** sign in to zenodo.org with the donerclass GitHub account and switch the integration on for the repo. Agents do not create accounts or accept terms.
- After the owner enables it, Builder publishes GitHub release `v1.0.0-data-2024`; Zenodo archives it and issues a DOI.
- Then add the DOI badge to README, a "How to cite" block on /methodology and /data, and the DOI to CITATION.cff.

Recommended citation format to display:
> Donor Class Team. (2026). DONOR CLASS: Committee-to-Candidate Contributions to the 119th Congress, 2023-2024 FEC Cycle (v1.0.0) [Data set]. Zenodo. https://doi.org/[DOI]

Optional later: mirror to Harvard Dataverse (also free, DOI-issuing). Not required for v1.
